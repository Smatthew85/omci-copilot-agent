# omci-copilot-agent

Knowledge base and tooling for a GitHub Copilot agent that analyzes ITU-T G.988 OMCI messages and helps diagnose failures.

## ME Catalog Extractor

The ME catalog is generated from [`github.com/opencord/omci-lib-go/v2`](https://github.com/opencord/omci-lib-go) using:

```bash
go run ./cmd/extract-me-catalog -out knowledge/me-catalog
```

This creates one JSON file per ME and updates `knowledge/me-catalog/INDEX.md`.

## Automation

`.github/workflows/sync-me-catalog.yml` runs the extractor weekly and on manual dispatch to keep `knowledge/me-catalog/` synchronized with the extractor output.

## Copilot Agent Knowledge Base

For OMCI ME class and attribute/access-rule decisions, use `knowledge/me-catalog/*.json` as the authoritative source generated by `cmd/extract-me-catalog`.

## Copilot Agent Knowledge Base

The `knowledge/` directory and `.github/copilot-instructions.md` together configure a **GitHub Copilot AI agent** specialized in OMCI protocol analysis and ONU provisioning failure diagnosis.

### Copilot Instructions

[`.github/copilot-instructions.md`](.github/copilot-instructions.md) defines the agent's persona, diagnostic methodology, response format, and guardrails. Copilot automatically applies these instructions when you ask questions in this repository.
